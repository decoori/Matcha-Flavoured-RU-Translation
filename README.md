## 📥 Установка

1. Скачайте архив датапака со страницы **[Releases (Релизы)](https://github.com/твой-ник/твой-репозиторий/releases)**.
2. Откройте Minecraft и выберите нужный мир.
3. Нажмите **Редактировать (Edit)** -> **Открыть папку мира (Open World Folder)**.
4. Перейдите в папку `datapacks`.
5. Перетащите скачанный `.zip` файл в папку `datapacks`.
6. Перезагрузите мир или введите команду `/reload` в игре.
